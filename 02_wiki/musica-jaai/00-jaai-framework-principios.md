# JAAI Music Framework — Principios Centrales

Migrado desde el Project "Musica JAAI" de claude.ai el 2026-08-25 (instrucciones del proyecto). Nota atomica de referencia rapida; el detalle completo de cada tecnica vive en las notas hermanas de esta carpeta (fundamentos, performance prompting, Suno workflow, voice identity, composicion de letras, direccion vocal).

JAAI Music Framework trata a Suno/IA musical como motor creativo conversacional, interprete emocional, productor y performer virtual. Meta: NO canciones IA al azar, sino musica emocionalmente autentica con identidad sonora intencional, voces humanizadas y storytelling cinematografico.

## Logica central

La IA sigue: contexto, intencion emocional, phrasing, formatting, lenguaje de produccion, direccion performativa.

Evitar prompts vagos ("make it human", "make it natural", "make it emotional"). Usar direccion precisa.

MAL: "Make vocals emotional."
BIEN: "Intimate vulnerable male vocals with subtle breathiness, emotional cracks, realistic breaths and conversational phrasing."

MAL: "Make it epic."
BIEN: "Cinematic alternative rock anthem with soaring choruses, wide stereo guitars and cathartic emotional release."

## Estructura del framework

- Main Genre = fundacion (arreglo, ritmo, identidad). Ej: Alternative Rock, Dream Pop, Psychedelic Folk, Indie Electronic, Blues Rock.
- - Secondary Tags = sabor (cinematic, nostalgic, analog warmth, dark atmospheric, live concert energy, raw garage rock, haunting harmonies).
  - - Vocal Descriptors = textura humana (tono, phrasing, imperfecciones, intensidad emocional).
    - - Emotional Language = atmosfera (como se SIENTE la cancion).
      - - Lyrics = performance oculta (pacing, respiracion, hooks, phrasing, entrega emocional). Se escriben como PERFORMANCE, no como poesia.
       
        - ## Voice casting (estilos base)
       
        - Classic Arena Rock, Modern Alternative, Post-Grunge, Southern Rock, Female Symphonic Rock, Dark Gothic Rock, Pop Punk/Emo, Blues Rock. Detalle completo en 04-voice-identity-engineering.
       
        - ## Lenguaje de produccion
       
        - cinematic production, vinyl mastered, atmospheric reverb, wide stereo image, shimmering guitars, deep rounded low-end, spacious pads, live concert energy.
       
        - ## Era locking
       
        - Usar anios para estabilizar identidad (ej. 2026 indie alternative rock, 1997 post-grunge, 1984 synthwave). Estabiliza mezcla, mastering, estilo vocal.
       
        - ## Humanizacion
       
        - Nunca decir "make it human". Describir: respiraciones reales, timing imperfecto, inestabilidad emocional, consonantes expresivas, entrega contenida, phrasing conversacional.
       
        - ## Formatting = direccion performativa
       
        - ( ) = susurros/pensamientos internos
        - [ ] = estructura/instrucciones
        - [ ] ~ = vibrato/sustain
        - [ ] * = alargamiento silabico
        - [ ] ... = duda/respiracion
        - [ ] MAYUSCULAS = intensidad
        - [ ] Saltos de linea = espacio para respirar
        - [ ] Puntuacion minima = flujo mas suave
       
        - [ ] ## Metatags y tag stacking
       
        - [ ] Metatags = instrucciones de performance, ej. [Verse 1] [Explosive Chorus] [Minimal instrumentation] [Atmospheric build]. Tag stacking: combinar 3-5 tags juntos.
       
        - [ ] ## Negative prompting
       
        - [ ] Usar Exclude Styles para evitar cliches IA: trap hi hats, cheesy EDM drops, autotuned vocals, hyperpop synths.
       
        - [ ] ## Personas
       
        - [ ] Usar Personas para continuidad vocal entre canciones/albumes y branding de artista.
       
        - [ ] ## Weirdness y Style Influence
       
        - [ ] Weirdness: control de experimentacion (bajo = seguro, alto = caotico/original). Style Influence: control de obediencia al prompt (bajo = improvisacion, alto = precision).
       
        - [ ] ## Principio final
       
        - [ ] JAAI Music Framework = direccion musical IA + ingenieria emocional + storytelling cinematografico + diseno de performance vocal + arquitectura sonora + creacion musical humanizada con IA. Tratar a la IA como vocalista, productor, banda, arreglista y colaborador creativo. Cada prompt debe funcionar como direccion artistica, guia emocional, ingenieria de performance y arquitectura sonora.
