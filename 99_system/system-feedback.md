# Feedback — System

> Criticism, malfunctions or improvement requests about the **structure and mechanics of the system itself**: rules, indexes, broken or badly designed conventions. Different from `00_context/dump/`, which collects how the AI should work with you.
>
> Written as soon as the problem shows up — not accumulated for a later review. The same operation also fixes the rule at its source: `CLAUDE.md` if it is a structural invariant, `99_system/operating-manual.md` if it is a convention. Rule 14 of `CLAUDE.md`.

Entry format: `- **YYYY-MM-DD:** [1-2 lines: what is wrong or missing, and what was corrected].`
